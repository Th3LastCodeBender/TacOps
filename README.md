## Setup sviluppo (Linux + VS Code + clangd)
1. Clona il repo ed esegui `git lfs pull`
2. Apri `TacOps.uproject` nell'Editor e fai *Tools > Refresh Visual Studio Code Project*
3. Lancia `./Tools/install.sh`
4. In VS Code: *Developer: Reload Window*

Dopo ogni *Refresh Visual Studio Code Project* rilancia `ue-clangd-setup` nella cartella del progetto.
